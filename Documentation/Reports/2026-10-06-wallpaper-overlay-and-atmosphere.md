# Wallpaper navigation overlay and Themes atmosphere

The user requested that Wallpaper's navigation overlap the wallpaper instead of occupying a separate navy section, and that its background reuse the Themes page's style.

Wallpaper now fills the main window behind the unchanged shared primary/secondary navigation and the existing source/search/favorites capsule. Its chrome is an overlay rather than a safe-area reservation. The hero reserves room for its title/actions within the image; filtered results start below the floating controls. A transparent black gradient preserves contrast over bright media and scrolling tiles, fading continuously into the page without a solid header edge.

`WallpaperAtmosphere` feeds the selected wallpaper into the existing `ThemeAtmosphere` renderer: navy canvas, pooled accent light, secondary haze, cached vignette and lower fade. It also uses Themes' existing `ThemePreviewCache.softened` image preparation. Muted images use faint haze and a blue/violet fallback, rather than lighting the whole canvas gray. Existing Themes callers retain their original rendering. The initial live screenshot exposed a washed-out muted-image background; this was corrected in the final color treatment.

Background preparation runs on source changes, using a 640-pixel still, a local library thumbnail or a static Art snapshot. The blur runs off the main actor and cancellation prevents old selections from replacing the current background. This creates no extra live wallpaper player and performs no blur per animation frame. The original hero playback/hover rules, media services, source rails, library sorting/filtering/import/detail controls remain.
