# 2026-10-03: wrap-up (cleanup, logged-error fixes, page-switch smoothness)

## Decided
- The overnight redesign (`redesign/ui`) is **not** taken. It stays as a local branch, unmerged and unpushed. Work continues on `perf-audit`.
- **Collections and Art pages removed** (pills, `AppPage` cases, the Collections file; Favorites moved to `Studio/FavoritesPage.swift`). Home lost its Art tile and Art rail. Generative art is still the Wallpaper page's Art source; `allset://page/art` and `-openPage art` open it there.

## Fixed (found in the app's own error log, `log show --predicate 'process == "AllSet"'`)
- Music widget: `ForEach` keyed by `\.x` over screw positions with repeated x (SwiftUI "ID occurs multiple times", 130 log faults).
- AI Screenshot: Esc during capture opened a file that was never written.
- Theme preview cache read files before checking they exist (one ImageIO error per miss).
- Core Audio listeners removed from devices/processes that had gone (`AudioObjectExists`).
- User-cancelled library fetches no longer logged as errors.

## Smoothness
- `Deferred` (Design/DesignComponents.swift): below-the-fold content built a moment after a page appears, under `PageVeil`'s Core Animation fade. Used for Themes' shelves, Home's lower rails and the Wallpaper page's lower aerial rails. Worst single frame on a switch: Themes ~110 → ~70 ms, Home ~118 → ~65 ms, Wallpaper ~90 → ~70 ms (total work unchanged; split over two frames).
- A lazy `BleedScrollPage` was tried and reverted: faster switches but Themes scroll CPU 15% → 51%.
- Aerial previews decode off the main thread, ready to draw, kept in a 60-item cache (`AerialCatalog.previews`, trimmed under memory pressure); the JPEG write is off main too.
- Clipboard and My Photos thumbnails use `FileThumbnail` (off-main, sized, cached) instead of full-size `AsyncImage`.
- `AppIconCache` caches Launch Services lookups and app names (they ran per row redraw).
